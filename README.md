# Tabletop Simulator Joker
This repository is for keeping and updating the scripts needed for Joker on Tabletop Simulator.

Joker is a team marble race: odd seats play against even seats, cards move your marbles round the board, and you
bonk the other team's marbles back to start. These scripts set the table up for 4, 6 or 8 players and run the game:
turns, bots for empty seats, stats, and the host's tools.

## Layout
```
src/       the scripts. Global.-1.lua is the Global script's table of contents; Buttons/ are the button objects'
           scripts; bot/ game/ play/ ui/ host/ hold the game; the files at the top set the table up
build/     what TTS runs, generated by build.lua (not committed)
tests/     test suites and a mock of the TTS API
tools/     pushing to TTS, the flag server, analysis tools
docs/      documentation
data/      flags and game logs written by the tools (not committed)
```

## Working on it
You need Lua 5.3 or newer (`brew install lua`) and Python 3. Everything runs from the repository root.

1. **Edit** files in `src/`. Never edit `build/`, which is regenerated.
2. **Test:** `./tests/run_all.sh` builds and runs every test suite. It ends with `ALL TESTS PASSED`.
3. **Push to the game:** open the save in Tabletop Simulator (use a dev copy, not the main save, until you've
   checked it), then run `./tools/push_to_tts.sh`. It builds and sends every script; TTS saves and reloads the
   game.
   - Don't push into a game people are playing: it reloads straight away.
   - VS Code's "Save And Play" also works for small changes, but its TTS extension cuts off scripts this size.
4. **Check in TTS** whatever the mock can't: positions, glow, sizes, physics.
5. **Commit and push** to GitHub. Then update the main save the same way as step 3.

The source files use `--#include "path.lua"` to pull in other files. `lua build.lua` resolves them; each entry
script in `src/` (`<object name>.<GUID>.lua`) becomes one file in `build/`.
